# 2주차 검증 기록

## 후속: 영상 열기 진입 개선

사용자가 버튼을 찾지 못한 문제를 반영했다. 기존에는 검사 선택 후 시리즈 상세 아래 작은 텍스트 버튼만 나타났다. src/App.tsx에서 왼쪽 검사 목록을 클릭 가능한 선택 UI로 변경하고 한 검사만 있을 때 자동 선택한다. src/IntakePanel.tsx에 항상 보이는 시리즈 선택 목록과 파란 영상 열기 버튼을 배치했다. 미선택 상태는 비활성화하고 복수 시리즈는 임의로 선택하지 않는다. 저장/등록 중 검사 선택을 잠그고 이전 검사 저장 응답이 새 검사에 표시되지 않도록 검사 ID를 확인한다.

검증: npm run build 성공. 실제 Edge의 기존 4개 브라우저 테스트 통과(초기 버튼 노출/비활성, 한 검사/시리즈 자동 선택 후 활성, 왼쪽 검사 클릭 추가 확인). 변경된 시리즈 목록의 접근성 역할을 기준으로 테스트를 갱신했다. 운영 API 및 의료 데이터는 변경하지 않았으며 새 정적 번들을 제공한다. 브라우저에 기존 번들이 열려 있으면 Ctrl+R로 갱신한다.

기준일: 2026-11-15 / 요구사항 v0.4 / 목표 W2-01~06

## 좌표·수치 기준

합성 기준 데이터 허용오차: HU 1e-4, LPS 좌표 및 거리 1e-4mm. 정렬 전 위치 [10,20,34], [10,20,30], [10,20,32]는 정상축 투영으로 정렬되고 간격 [3,2,2]mm가 된다. 인덱스 [1,1,1]의 LPS는 [13,22,32]mm, [0,0,0]→[1,1,2] 거리는 sqrt(29)mm와 일치했다. 사선·반전 방향도 기준 수식과 비교했다.

허용오차는 API의 합성 기하 계산 검증 기준이며 마우스로 찍은 화면 측정 오차나 임상 정확도 기준이 아니다. 화면 Length 도구는 동작/단위 표시를 확인했고 원본 인덱스의 수치 검증은 별도 API에서 수행했다. 화면에서 직접 찍은 점의 모든 환자 좌표/보간 오차를 1e-4mm로 검증했다고 주장하지 않는다.

- 기존 등록/직접 입력·버전·설정·연결 오류 복구 및 3종 해상도 회귀 통과.
- 초기 OHIF 투어 오버레이와 공급자 안내를 테스트에서 사용자가 누르는 순서로 닫았다. 운영 화면에서 공급자 안내를 강제로 제거하지 않음.

- 측정 요청 중 시리즈가 바뀌면 이전 결과가 새 시리즈에 표시되지 않도록 generation guard 추가.

## 격리와 남은 범위

테스트는 임시 API DB와 QA Orthanc(8043)을 사용했다. 운영 Orthanc(8042)과 API DB에 합성 CT를 넣지 않는다. 모든 QA 자료·캡처·네이티브 바이너리·인증 config는 Git 제외다.

운영 확인 시 등록된 검사는 1건, 합성 QA 표식 검사 0건, 진행 중 등록 작업 0건이었다. 작업 중 사용자 측에서 등록한 자료는 변경·삭제하지 않았다. 환자 이름·소견·UID 등 실제 내용은 검증 문서에 복사하지 않았다. QA 영상 프로세스는 검증 후 종료했다.

초기 지원은 비압축 평행 직교 단일 프레임 CT다. 압축·Enhanced·gantry tilt·불규칙 절편 보정은 지원하지 않는다. 단일/두 절편은 스택만 지원하고 MPR에는 최소 3절편이 필요하다. 균일하게 누락된 절편은 현재 보유 영상의 간격만으로 판별할 수 없다. 전체 geometry 확인은 원본을 순차 디코딩하므로 큰 CT의 첫 열기 시간은 별도 실측이 필요하다.

현재 픽셀 검사와 원본 수치 API는 별도 검사마다 파일을 읽는다. 전체 임상 데이터에서 처리시간·메모리·성능 목표는 아직 확정하지 않았으며 NFR-07/VAL-01의 나머지 기준으로 추적한다. 원본 viewer 측정/주석 저장, 분할 3D·AI·대조·백업/복원·임상 성능 평가는 후속 작업이다.
