## 검증

`data/ct-review-browser-results/user-manual-1280.png`, `user-manual-390.png`를 시각 확인했다. 한글 제목/목차/순서/버튼이 읽히고 가로 잘림이 없다. 테스트 자료/화면은 격리된 합성 CT QA 서버 8005에서 생성하며 운영 자료를 사용하지 않았다.
