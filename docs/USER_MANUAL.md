# 흉부 CT 검토실 사용자 매뉴얼

12개 장을 목차별 페이지로 나누어 한 번에 한 장씩 표시한다. **목차·이전·다음**, 아래 현재/전체 페이지 번호로 이동한다.

현재 화면 기준의 본문은 [로컬 HTML 매뉴얼](../public/user-manual.html) 한 곳에서 관리한다. 인터넷 없이 파일을 직접 열어 읽을 수 있다.

- 실행 중인 앱: 상단 **사용자 매뉴얼** 또는 [사용자 매뉴얼 열기](http://127.0.0.1:8000/user-manual.html).
- 인쇄·PDF: 매뉴얼 상단 **현재 페이지 인쇄 / PDF**, 브라우저 인쇄 대상에서 PDF 선택. 선택한 장만 출력한다.
- 찾기: 목차 링크로 장을 선택하고 **Ctrl+F**로 현재 페이지를 검색한다. 모바일에서는 상단 **목차**로 열고 닫는다.

처음 사용할 때는 **CT 등록 → 종합 분석 → 후보 확인 → 근거 영상 → 검토 기록 저장**을 따른다. 병원 소견 입력·대조는 선택이다. 자세한 단계와 상태/퍼센트·문제 해결·백업/종료는 본문을 참고한다.

문서 기준: API 0.7.0, 2026-11-16. 새 UI-07, WBS 1·7·9·10. 본문 파일만 수정하며 별도 복사본을 만들어 내용이 달라지지 않도록 한다. 검증: docs/verification/user-manual.md.
