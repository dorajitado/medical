# 진료 적용 평가 준비 절차 — VAL-05

갱신: 2026-11-16. **전문의 정답 자료·검토자 아직 없음. 진료 성능 미검증.** 사용자의 답변에 따라 평가 도구와 절차를 먼저 준비한다. 기능·좌표·자원 시험을 진료 적용 통과로 바꾸지 않는다.

## 확보할 자료와 사전 결정

- 사용 목적과 소견별 대상: 결절, 흉수, 심낭삼출을 독립적으로 정의. 박스 탐지와 분할/계측의 평가를 구분한다.
- 검토자와 정답: 영상의학 전문의 확인 원본 CT, 병변별 위치/종류·분할/측정법·의심/부정·판정 불가와 adjudication 이력. 병원 소견서 미언급은 음성 정답이 아니다.
- 촬영 조건: 조영 시기/프로토콜·재구성·두께/간격·장비·촬영 범위·아티팩트별 표본 구성. 일반 조영 CT를 CTPA로 분류하지 않는다.
- 연결 기준/오차·성능 목표: 전문가가 병변 일치 기준, 작은 병변/말초 병변, 표본 수, 허용 측정 오차와 인수 기준을 **평가 전에** 확정한다. 현재 숫자 목표는 미정이다.
- 모델 버전·가중치 SHA·전처리·임계값을 동결하고 학습/개발·검증·독립 테스트를 환자 단위로 분리한다. 공개 모델의 기존 학습 자료와 중복 여부도 조사한다.

## 현재 제공하는 도구

왼쪽 **평가 · 지원 범위**에서 선택 검사의 원본 해시에 연결한 준비 사례를 개발/검증/테스트로 등록하고 평가대장 JSON을 저장한다. 같은 원본 해시와 제공된 비식별 환자 그룹의 분할 중복을 거부한다. 환자 그룹을 모르면 준비 상태까지만 사용하며, 동일 환자의 다른 검사 누출을 자동으로 해결했다고 가정하지 않는다.

전문 검토 완료 사례는 로컬 API `POST /api/studies/{study_id}/evaluation-cases`로 등록할 수 있다. 필드: `split`, `reference_source`, `reviewer`, `payload`. `payload`에는 `expert_reviewed`, 비식별 `patient_group`, 정답 파일 `reference_sha256`, 소견 종류별 `counts` (`tp`, `fp`, `fn`)와 평가 기준/근거를 기록한다. 실명·주민번호를 환자 그룹에 사용하지 않는다. 정답 파일 자체나 자동 채점기를 제공하는 기능은 아니다.

`GET /api/evaluation` 및 `GET /api/evaluation/export`는 최신 원본별 버전을 분리해 집계한다. 민감도 TP/(TP+FN), 정밀도 TP/(TP+FP), 사례당 FP를 종류·분할별로 계산한다. 평가된 사례/분모가 없으면 비율은 null이다. 같은 사례의 수정본을 독립 표본으로 중복 집계하지 않는다. 입력 수치는 검토자가 등록한 계수이며 앱이 정답을 인증하지 않는다. 항상 `clinical_acceptance=not_established`로 유지한다.

## 실제 평가와 인수

1. 자료/검토자 확보 후 사전 결정사항·버전·분할을 문서화한다. 표본 수와 신뢰구간 계산법을 전문가와 확정한다.
2. 판독소견서는 영상 모델 입력에 넣지 않는다. 모델 결과를 고정한 뒤 전문가 정답과 대조하고, 이후 병원 소견·사용자 해석을 별도로 검토한다.
3. 종류별 누락/위양성·검사당 FP·측정 오차·처리 실패/판정 불가와 촬영 조건별 결과를 보고한다. 실패/미지원/미분석을 음성 분모에 넣지 않는다.
4. 독립 테스트에서 사전 목표와 불확실성을 평가하고 담당 검토자가 사용 조건·미지원 조건을 확정한다. 미달 시 임계값을 조정한 뒤 같은 테스트셋을 최종 평가로 재사용하지 않는다.
5. 정답 출처·검토자·전처리·가중치·평가 원자료·결과·한계를 보존하고 요구사항 추적표 VAL-05를 별도로 갱신한다. 현재 단계에서는 이 인수 절차를 완료하지 않았다.

## 조건부 모듈

폐색전 공개 모델 연구는 존재한다. [PE 분할 연구와 공개 가중치 안내](https://arxiv.org/abs/2509.18308v3)는 CTPA와 별도 평가의 필요성 및 말초 색전의 어려움을 설명한다. 현재 앱에 해당 어댑터를 연결하지 않았다.

추가 구조는 [TotalSegmentator 공식 문서](https://github.com/wasserth/TotalSegmentator)를 기준으로 모듈별로 구분한다. 폐혈관·기도, 심장방 정밀 분할, 기타 병변을 하나의 완료 항목으로 묶지 않는다. `AI-10-A/B/C`는 AI-10 내부의 지원 범위 키이며 루트 요구사항 55개와 P0 분모 48개를 늘리는 별도 완료 체크가 아니다. 구조 분할을 폐색전/협착·심장 기능/질환 판정으로 바꾸지 않는다. 각 모델/가중치의 사용 조건·영상 입력·정답 평가가 충족된 뒤 별도 연결한다.
