1. 처음 사용하는 순서

CT 등록 → 종합 분석 → 후보 확인 → 근거 영상 → 검토 기록 저장

  1. 프로젝트 폴더의 start.cmd를 실행하고 로컬 앱을 엽니다.
  2. 왼쪽 검사 등록 → CT 폴더 선택으로 병원에서 받은 DICOM 폴더를 선택합니다. 파일 선택이 끝나면 등록이 시작됩니다.
  3. 등록이 끝나면 왼쪽 위 작업할 검사에서 이번에 볼 검사를 고릅니다.
  4. 종합 검토에서 CT 시리즈를 고르고 이번 CT 분석 시작을 펼칩니다.
  5. 실행할 항목과 사용 가능한 범위를 읽고 선택한 CT 시리즈와 분석 범위를 확인했습니다를 체크한 뒤 종합 분석 실행을 누릅니다.
  6. 진행 막대와 결과를 확인합니다. 후보 카드의 CT에서 위치 확인을 누르면 해당 실행의 CT·3D·후보 상세로 이동합니다.
  7. 종합 검토로 돌아와 필요한 메모를 저장하고 CT 종합 검토 저장 → CT 검토 PDF 저장을 누릅니다.
병원 소견서는 없어도 됩니다. 등록·분석·영상 확인·저장까지 CT만으로 사용할 수 있습니다. 소견과 대조하고 싶을 때만 선택 기능을 켭니다.
화면은 AI가 제안한 확인 후보를 보여줍니다. 현재 진료 적용 성능은 검증 전입니다. 분석 완료·100%·후보 없음은 정상 판정이나 확정 진단을 뜻하지 않습니다.

2. 앱 실행과 준비

한 번 설치가 끝난 PC라면 start.cmd를 실행하고 브라우저에서 http://127.0.0.1:8000을 엽니다. 실행 창을 유지해 주세요. Docker는 사용하지 않습니다.

  • 상단에 로컬 저장소 연결됨이 표시되는지 확인합니다.
  • 새 화면이 보이지 않으면 Ctrl+F5로 다시 불러옵니다.
  • 준비물은 DICOM 원본 파일입니다. CT 사진을 캡처한 PNG/JPEG나 PDF만으로 영상 분석을 시작할 수는 없습니다.
  • 처음 설치한 PC에서는 영상 엔진·AI 모델 설치가 별도 필요합니다. 설치 명령은 프로젝트 README에 있습니다. 검사 등록의 분석 모델 준비 상태와 종합 검토의 각 항목 사유를 확인합니다.

이 매뉴얼은 앱 상단 사용자 매뉴얼에서 새 창으로 열립니다. 목차 또는 아래 이전 / 다음으로 페이지를 이동합니다. Ctrl+F는 현재 표시된 페이지에서 검색합니다. 출력은 상단 현재 페이지 인쇄 / PDF를 사용하세요. 선택한 페이지를 출력하며 PDF 저장은 브라우저 인쇄 화면의 대상에서 선택합니다.

3. CT 등록과 선택

폴더를 등록하기

  1. 검사 등록에서 CT 폴더 선택을 누릅니다. 하위 폴더에 DICOM이 있어도 파일을 수집합니다. 일부 파일만 넣을 때는 파일 선택을 사용합니다.
  2. 브라우저가 폴더 업로드 확인을 표시하면 선택한 폴더가 맞는지 확인합니다. 파일은 본인 PC의 로컬 서버로 전달됩니다.
  3. 등록·중복·제외·실패 수와 사유를 확인합니다. 중복 파일은 다시 추가되지 않습니다. 등록된 파일이 있다는 것만으로 영상/모델 적합성이 확인된 것은 아닙니다.
  4. 중지하려면 남은 등록 취소를 누릅니다. 이미 등록된 파일은 남아 있습니다.

검사와 시리즈의 차이

검사는 한 촬영 묶음, 시리즈는 그 안의 영상 묶음입니다. 같은 검사에도 서로 다른 재구성/절편 두께의 시리즈가 있을 수 있습니다. 왼쪽 작업할 검사를 선택한 다음 종합 검토에서 분석할 시리즈를 고릅니다. 자료가 여러 개면 자동으로 특정 시리즈를 정답으로 고르지 않습니다.

원본 CT 먼저 보기로 선택한 입력을 살펴볼 수 있습니다. 현재 초기 지원은 일정한 간격/방향의 비압축 단일 프레임 CT입니다. 압축·Enhanced/다중프레임·공간정보 누락·기울어진 geometry 등은 제외/거부될 수 있습니다. 지원 사유를 확인하고 억지로 다른 파일 형식으로 바꾸지 마세요.

조영제를 사용했다는 사실만으로 폐색전 검사용 CTPA가 확인되거나 모든 흉부 소견이 분석되는 것은 아닙니다. 화면의 지원 범위를 확인하세요.

4. 종합 분석 실행

종합 검토 → 이번 CT 분석 시작을 펼치면 실행 항목이 나옵니다. 기존 완료 결과가 있으면 이 영역은 접혀 있을 수 있습니다.

항목앱에서 하는 일
구조와 위치 파악폐엽·기관·심장·대동맥의 구조를 나눕니다. 후보의 위치를 설명하는 데 사용하며 질환 탐지 건수로 세지 않습니다.
결절 의심 부위 찾기결절로 분류된 후보 영역과 계산 가능한 너비·부피를 제안합니다.
폐·심장 주위 액체 후보 찾기흉수/심낭삼출로 분류된 영역과 종류별 합산 부피를 제안합니다.
결절 의심 부위 추가 확인독립 MONAI 모델의 위치 상자를 제공합니다. 분할 장경/부피는 제공하지 않습니다.

준비되지 않았거나 입력 조건이 맞지 않는 항목에는 사유가 표시됩니다. 실행 준비 다시 확인으로 재조회할 수 있습니다. 실행할 항목을 고르고 확인 체크 후 종합 분석 실행을 한 번 누릅니다. 모델은 GPU에서 순서대로 실행됩니다.

퍼센트가 뜻하는 것

실행 완료 항목 수 ÷ 선택한 항목 수입니다. 네 항목을 선택했다면 한 항목 완료 시 25%, 전부 완료 시 100%입니다. 한 모델을 처리하는 동안 퍼센트가 그대로일 수 있습니다. 각 모델 내부 계산량/남은 시간의 추정치가 아닙니다.

  • 순서 대기 / 처리 중: 아직 완료하지 않은 항목입니다. 모델별 상태를 함께 보세요.
  • 실패 / 취소: 완료 비율에 포함하지 않습니다. 네 개 중 세 개 완료·한 개 실패면 75%로 남습니다.
  • 100%: 선택한 실행 항목이 끝났다는 뜻입니다. 결과의 의학적 정확도나 건강 상태를 뜻하지 않습니다.

중지하려면 진행 중인 종합 분석 취소를 누릅니다. 완료된 결과는 보존되고 대기/진행 작업은 취소 상태로 남습니다. 다시 실행하면 새 버전이 생성됩니다. 이번 CT 분석 시작 안의 실행 선택 목록에서 과거 종합 실행이나 모델별 최신 시도를 확인할 수 있습니다.

5. 결과를 읽는 방법

먼저 큰 제목과 결절 후보 / 폐 주위 액체 후보 / 심장 주위 액체 후보 카드를 봅니다. 분석한 범위와 아직 확인하지 않은 항목을 펼쳐 완료·실패·제외·미지원 범위를 확인합니다.

표시읽는 방법
AI 후보 제안 수모델이 표시한 제안 수입니다. 서로 다른 모델이 같은 부위를 제안할 수 있어 확정 병변 수와 다릅니다.
왼쪽/오른쪽 폐엽 위치같은 CT의 해부학 분할에서 대표점 위치를 추정한 것입니다. 위치 지도를 확인할 수 없으면 세부 위치 확인 전으로 표시합니다.
최대 너비 / 부피분류된 마스크에서 계산한 값입니다. 너비는 원본 촬영 단면의 계산값이고, 임상 RECIST 측정을 뜻하지 않습니다. 액체 영역은 종류별 합계입니다.
위치 상자만 제공탐지상자를 표시하는 모델입니다. 상자의 폭/부피를 실제 병변 크기로 읽지 않습니다.
모델 점수해당 모델의 독립 점수입니다. 악성 확률이 아니며 서로 다른 모델 점수를 평균하지 않습니다.
표시된 후보 없음실행한 분석 범위에서 제안이 없다는 뜻입니다. 정상·질환 배제를 뜻하지 않습니다.
일부 범위만 분석됨 / 상태 확인 필요완료하지 못한 항목과 사유를 확인합니다. 실패·취소·손상된 출처를 정상 결과로 바꾸지 않습니다.

후보 카드는 4개씩 표시됩니다. 종류 선택과 페이지 버튼으로 다른 후보를 봅니다. 가까운 위치의 다른 모델 제안 표시는 중복 가능성 안내이며 같은 병변이라고 확정한 것이 아닙니다. 측정·출처와 검토 기록을 펼치면 계산 방법·원본 단면·실행/후보 식별·좌표를 볼 수 있습니다.

현재 종합 검토는 위치용 구조·결절·흉수/심낭삼출 후보 범위입니다. 폐색전·기흉·폐실질 이상·림프절 등 모든 흉부 이상을 평가하는 화면이 아닙니다.

6. 원본 CT·3D 확인

  1. 후보 카드의 CT에서 위치 확인을 누릅니다.
  2. AI 분석 · 3D로 이동하면 해당 실행과 후보가 선택되고 CT 마스크 뷰·3D·후보 상세가 연결됩니다.
  3. 대표 절편과 주변 절편을 살펴봅니다. 3D는 선택한 실행의 실제 분할 또는 탐지상자를 표시합니다.
  4. 목록이나 3D에서 다른 후보를 선택할 수도 있습니다. 오른쪽 영역이 접혀 있으면 보조 패널 펼치기와 입체 구조 영역을 확인합니다.

일반 CT 열람

CT 영상 열람에서 시리즈를 선택하고 영상 열기를 누릅니다. OHIF 안내를 닫은 뒤 마우스 휠로 절편을 이동합니다. Zoom/Pan/Window Level 도구로 확대·이동·명암을 조절합니다. 영상에 초점을 두고 숫자 1은 연조직 창, 2는 폐창입니다. MPR은 뷰어의 레이아웃 메뉴에서 선택하며 최소 3절편이 필요합니다.

OHIF와 AI 마스크 뷰의 절편/창 설정은 독립적입니다. 종합 검토의 후보 위치 연결은 AI 마스크 뷰·3D·상세에 적용됩니다. OHIF가 자동으로 같은 단면으로 이동한다고 가정하지 마세요.

좁은 화면에서는 오른쪽 패널이 아래에 배치됩니다. 필요하면 작업 영역 확대 또는 뷰어의 별도 창 열기를 사용합니다.

7. 검토 기록·파일 저장

후보별로 메모 남기기

후보의 측정·출처와 검토 기록을 펼쳐 사용자 상태와 CT 후보 검토 메모를 입력하고 후보 검토 기록 저장을 누릅니다. 검토 전·사용자 확인 표시·확인 보류·후보 제외 표시는 사용자 기록이며 AI 원본이나 진단을 변경하지 않습니다. 입력만 하고 저장하지 않은 메모는 창을 닫으면 잃을 수 있습니다.

종합 검토를 고정된 버전으로 보관하기

  1. 원하는 분석 실행과 후보 검토 상태가 맞는지 확인합니다.
  2. 소견서를 포함하지 않으려면 병원 소견과도 대조하기 (선택)를 꺼 둡니다.
  3. CT 종합 검토 저장을 누릅니다. 그 시점의 후보·범위·사용자 검토·출처가 저장됩니다.
  4. 저장 기록 목록에서 원하는 버전을 선택한 뒤 CT 검토 PDF 저장 또는 CT 검토 JSON 저장을 누릅니다.

PDF는 읽고 공유할 검토 기록, JSON은 수치·좌표·버전·출처 관계를 보존하는 파일입니다. 이후 메모나 분석 결과를 바꿔도 이미 저장한 버전은 바뀌지 않습니다. 최신 내용을 반영하려면 다시 저장해 새 버전을 만드세요. 이 내보내기 파일은 전체 작업 공간 백업과 다릅니다.

8. 병원 소견 대조 선택

이 절은 소견서가 있고 대조하고 싶을 때만 진행합니다. 종합 검토의 대조 스위치는 기본 꺼짐입니다. 켰는데 자료가 없어도 CT 분석/저장은 사용할 수 있습니다.

  1. 판독소견 · 구조화에서 오른쪽 입력 영역의 출처를 고르고 직접 입력한 내용을 채운 뒤 선택 검사에 새 버전 저장을 누릅니다. 병원 소견 전사와 직접 작성·개인 메모를 구별합니다.
  2. 구조화할 소견서 버전을 선택하고 원문에서 소견 구조화를 누릅니다.
  3. 원문과 추출 항목을 대조해 부정·의심·과거 표현·위치·단위를 확인합니다. 필요하면 정정하고 정정 내용을 새 버전으로 저장합니다.
  4. 소견 · AI 대조에서 구조화 버전과 같은 검사/시리즈의 완료된 실행을 선택하고 선택 소견과 AI 후보 대조를 누릅니다. 연결은 원본 위치를 확인한 뒤 검토해 저장합니다.
  5. 종합 검토로 돌아와 병원 소견과도 대조하기 (선택)를 켜고 저장한 대조 버전을 선택합니다.

현재 분석과 실행 버전이 다른 대조는 자동으로 합쳐지지 않습니다. 소견이 있다는 것과 연결 대조가 선택됐다는 것도 다릅니다. PDF/JSON에 소견을 넣을지 스위치와 현재 대조 상태를 확인한 뒤 새 검토 기록을 저장하세요.

문서 파일이 있다면 문서 · OCR → 문서 선택 (32 MiB 이하)를 사용합니다. PDF/PNG/JPEG를 지원합니다. 추출 텍스트를 원문과 비교·수정하고 확인한 뒤 문서 출처로 소견 저장해야 합니다. 추출 실패가 원문 없음/정상 소견을 뜻하지 않습니다.

9. 메뉴별 용도

왼쪽 메뉴사용할 때
종합 검토CT만으로 일괄 실행·쉬운 결과·근거 이동·검토 저장을 할 때. 기본 시작 화면입니다.
검사 등록DICOM 폴더/파일을 넣고 등록 내역·모델 준비 상태를 볼 때.
CT 영상 열람원본 CT, MPR, 거리/HU를 확인할 때.
AI 분석 · 3D개별 모델 실행/이력과 마스크·탐지상자·후보/3D 근거를 볼 때.
판독소견 · 구조화선택 기능. 소견을 입력하고 구조화 결과를 원문과 대조·정정할 때.
소견 · AI 대조선택 기능. 소견 항목과 AI 후보의 연결을 검토할 때.
검토 · 정리본사용자 판단·진료 질문·기존 소견 중심 정리본을 관리할 때. CT 중심 저장은 종합 검토에서 할 수 있습니다.
문서 · OCR선택 기능. 문서 원본과 추출/수정한 전사 내용을 구별해 보관할 때.
독립 모델 비교같은 CT의 두 결절 모델 제안을 나란히 검토하고 연결할 때. 점수를 합쳐 진단하지 않습니다.
이전 CT 비교이전 검사와 수동 기준점/측정을 비교할 때. 현재 부분 구현으로 자동 전체 영상 정합·성장 판정을 제공하지 않습니다.
평가 · 지원 범위모듈 지원/미지원과 평가 준비 상태를 확인할 때. 임상 성능 통과 여부와 구별합니다.
백업 · 데이터 관리전체 작업 공간 백업과 삭제 범위를 확인할 때.

좁은 화면에서는 상단 메뉴 버튼으로 왼쪽 메뉴를 엽니다. 메뉴 이동 중 검사·열린 시리즈·작성 중인 편집 상태를 보존하지만, 다른 검사/시리즈로 변경하면 해당 자료의 상태로 바뀝니다. 중요한 입력은 이동/종료 전에 저장하세요.

10. 자주 막히는 부분

상황확인할 것
서버 연결 필요start.cmd 실행 창이 유지되는지 확인하고 앱의 새로고침/재시도를 누릅니다. 브라우저 주소가 127.0.0.1:8000인지 확인합니다.
등록한 CT가 안 보임등록·제외·실패 수와 사유, 왼쪽 작업할 검사 선택을 확인합니다. 등록 메뉴와 종합 검토는 용도가 다릅니다.
종합 분석 실행 버튼이 비활성검사/시리즈 선택, 실행 가능한 항목 선택, 범위 확인 체크를 확인합니다. 이미 처리 중이거나 모델/입력이 미지원이면 사유를 확인합니다.
퍼센트가 한동안 그대로각 모델 하나가 끝날 때 올라갑니다. 처리 중인 항목을 확인합니다. 분석 중에는 절전/종료를 피하고 실패 표시가 있으면 사유를 읽습니다.
분석 실패 / 메모리 부족실패 사유와 모델 준비·입력 조건을 확인합니다. GPU를 많이 쓰는 다른 작업을 정리한 뒤 필요한 항목만 새 실행할 수 있습니다. 실패한 결과는 정상으로 읽지 않습니다.
원본 영상/3D가 안 열림선택 시리즈와 영상 서비스 상태를 확인합니다. 3D는 브라우저 WebGL/표시 한도에 영향을 받을 수 있습니다. CT 마스크·상세 오류도 별도로 확인합니다.
결과와 소견 대조가 안 맞음같은 검사/시리즈인지, 대조가 현재 실행 버전으로 저장됐는지 확인합니다. 자동 연결 후보는 사용자 확인과 다릅니다.
메모 수정 후 PDF가 그대로기존 PDF/기록은 저장 시점 버전입니다. 메모 저장 후 CT 종합 검토를 다시 저장하고 새 버전을 내려받습니다.
소견서가 없음병원 대조를 꺼 둔 채 CT만으로 진행하면 됩니다.

11. 백업·삭제·복원

백업

등록/분석/문서 처리가 끝난 뒤 백업 · 데이터 관리 → 현재 작업 공간 백업을 누릅니다. 생성된 백업을 다운로드하고 검증·복원 안내로 확인합니다. DICOM 앱 복사본·분석/문서·소견/검토 기록을 포함하며 모델 런타임·영상 캐시 등은 제외합니다. 백업에도 의료정보가 포함됩니다.

삭제

선택 검사 삭제 범위 확인으로 대상과 개수를 읽고, 화면의 삭제 확인 문구를 입력해야 확인한 검사 삭제 실행이 활성화됩니다. 앱 관리 복사본/기록을 삭제하며 처음 선택한 외부 CT 폴더·기존 백업은 유지합니다. 불필요한 시험 삭제를 하지 말고 먼저 백업하세요.

복원

실행 중인 앱에서 즉시 복원하는 버튼은 없습니다. 백업의 안내를 읽고 앱·영상 서비스를 종료한 뒤 프로젝트의 restore-backup.ps1을 사용합니다. 확인 문구와 백업 ID가 필요합니다. 구체적 절차는 프로젝트 docs/LOCAL_DATA_MANAGEMENT.md의 오프라인 복원 항목을 따르세요.

12. 종료와 다음 실행

  1. 입력한 검토/메모를 저장하고 필요하면 CT 종합 검토 버전과 백업을 만듭니다.
  2. 등록·분석·문서 처리가 끝났는지 확인합니다. 중지할 작업은 해당 화면에서 취소합니다.
  3. 앱 실행 터미널에서 Ctrl+C로 서버를 종료합니다. 브라우저 탭만 닫으면 서버가 계속 실행될 수 있습니다.
  4. 다음에 start.cmd로 실행하고 작업할 검사/시리즈와 저장한 실행/검토 버전을 다시 고릅니다.

서버 중단 중이던 분석은 다음 실행에서 실패/중단으로 표시됩니다. 이전 완료 결과를 덮어쓰지 않으며 필요한 경우 새 분석을 시작합니다. 저장된 원문·AI 출력·사용자 판단은 서로 구별해 보존됩니다.
